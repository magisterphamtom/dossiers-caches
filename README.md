# Masquer les dossiers de journaux

Module Foundry VTT (v13 et v14) : faites le ménage dans l'onglet **Journaux** en masquant d'un clic droit les dossiers dont vous n'avez pas besoin en ce moment.

## Utilisation

- **Clic droit sur un dossier → « Masquer ce dossier »** : le dossier et tout son contenu (sous-dossiers compris) disparaissent de la liste.
- Un bouton **œil barré** apparaît dans l'en-tête de l'onglet, avec le nombre de dossiers masqués. Cliquez dessus pour **les afficher temporairement** (grisés) ; cliquez à nouveau pour les recacher.
- Dossiers affichés : **clic droit → « Réafficher ce dossier »**, ou **« Réafficher tous les dossiers masqués »**.

Rien n'est supprimé ni déplacé : le module ne change que l'affichage. Les journaux restent accessibles par les liens, la recherche globale et les autres modules.

**Chacun sa liste** : les dossiers masqués sont enregistrés pour chaque utilisateur (MJ ou joueur), et suivent son compte d'un appareil à l'autre. Masquer un dossier chez vous ne le cache pas aux autres. Pour cacher un journal aux joueurs, utilisez les droits d'accès habituels de Foundry.

## Réglages (personnels)

| Réglage | Rôle | Par défaut |
|---|---|---|
| Affichage des dossiers masqués | **Masquer complètement** ou **Griser** (visible mais estompé). | Masquer complètement |
| Aussi dans les autres onglets | Active le même menu dans les onglets Acteurs, Objets, Scènes, Tables… (recharge la page). | Non |

## Installation

Dans Foundry : **Modules complémentaires › Installer un module**, puis collez ce lien de manifeste :

```
https://github.com/magisterphamtom/dossiers-caches/releases/latest/download/module.json
```
